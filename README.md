# Clean Setup

1. Generate an SSH key an add it to Github
2. Install [Homebrew](https://brew.sh/)
3. `git clone git@github.com:mbfisher/dotfiles`
4. Run `install.sh`
5. Open iTerm

## Peripherals

### Home

- Keychron K3 Max keyboard: its 2.4 GHz `Keychron Link` receiver (no logo) is connected to the Dell
  monitor's KVM, so the keyboard follows the monitor between the work MacBook and personal/gaming PC.
- Work MacBook mouse: Apple Magic Mouse connected directly over Bluetooth.
- Personal/gaming PC mouse: Keychron M6 using its 2.4 GHz `Keychron Link-KM` receiver (logo), connected
  directly to the PC. The mouse receiver does not go through the KVM.

### Office

- Separate Keychron K3 Max keyboard connected to the work MacBook over Bluetooth.
- Separate Apple Magic Mouse connected to the work MacBook over Bluetooth.
